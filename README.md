# Лабораторная работа №1: Развертывание базовой инфраструктуры в облачной платформе

**Дисциплина:** Технологии глобальных и отраслевых веб-служб (ТГиОВ)  
**Цель:** Практическое освоение методологии применения облачных платформ веб-служб уровня PaaS (Platform as a Service), приобретение навыков сквозного развертывания динамических серверных приложений из систем контроля версий.

---

## 📌 Описание сервиса
Серверное веб-приложение разработано на платформе **Node.js** с использованием фреймворка **Express**.  
Приложение спроектировано для развертывания в PaaS-облаке **Render.com** в качестве динамического веб-сервиса (Web Service).

### Возможности сервиса:
- Конечная точка `GET /`: возвращает адаптивный HTML-дашборд со статусом сервиса и метаданными окружения. При передаче заголовка `Accept: application/json` или параметра `?format=json` возвращает структурированный JSON-объект.
- Конечная точка `GET /api/info`: возвращает подробную диагностическую информацию об облачной платформе, времени непрерывной работы (uptime), версии рантайма и доступных endpoint'ах в формате JSON.
- Конечная точка `GET /health`: легковесный endpoint для проверки жизнеспособности (health check) сервиса.

## 🚀 Локальный запуск

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск приложения:
   ```bash
   npm start
   ```

3. Откройте в браузере: `http://localhost:3000`

---

## ☁️ Развертывание на Render.com

1. Зарегистрируйтесь на [Render.com](https://render.com/) через ваш GitHub-аккаунт.
2. Нажмите **"New +"** и выберите **"Web Service"**.
3. Подключите свой GitHub-репозиторий с данным проектом.
4. Задайте параметры:
   - **Name:** `tgiov-lab1-cloud-service` (или любое другое имя)
   - **Language / Runtime:** `Node`
   - **Region:** `Frankfurt (EU Central)` или `Oregon (US West)`
   - **Branch:** `main` (или `master`)
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
5. Нажмите кнопку **"Deploy Web Service"**.
6. После завершения сборки приложение станет доступно по выданному URL-адресу: `https://<ваше-имя>.onrender.com`.

## 🌐 Спецификация API

| Метод | Путь | Формат ответа | Описание |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | HTML / JSON | Главная страница статуса инфраструктуры |
| `GET` | `/?format=json` | JSON | Метаданные сервиса в машинно-читаемом виде |
| `GET` | `/api/info` | JSON | Подробная информация об окружении и рантайме |
| `GET` | `/health` | JSON | Healthcheck статус работоспособности (`ok`) |
